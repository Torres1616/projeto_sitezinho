# 📱 Social Media Tree Simulator

Um simulador de interface mobile interativo desenvolvido para centralizar links de redes sociais de forma elegante e dinâmica.

## 🎯 O Projeto
O objetivo foi criar uma experiência de usuário (UX) que simula o uso de um smartphone. Ao clicar nos ícones laterais, o conteúdo interno do "aparelho" é alterado dinamicamente sem a necessidade de recarregar a página principal.

## 🛠️ Recursos Técnicos Utilizados
* **Navegação via Iframe:** Uso estratégico do atributo `target` para controle de fluxo de conteúdo.
* **Layout Responsivo & Fixo:** Centralização avançada com `transform: translate` e posicionamento absoluto.
* **Efeitos de UI/UX:** Transições suaves, estados de hover personalizados e bordas arredondadas (`border-radius: 50%`).
* **Design Mobile-First:** Foco na estética de aplicativos móveis.

## 📂 Estrutura do Projeto
- `index.html`: Página principal com a moldura do smartphone.
- `home.html`: Tela inicial interna do simulador.
- `facebook.html`, `instagram.html`, etc: Páginas de destino integradas.
- `phone.css`: Estilização estrutural do layout.
- `tela.css`: Estilização interna das telas das redes sociais.
